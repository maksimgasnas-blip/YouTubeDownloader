# YouTube Downloader

Небольшая оболочка Windows для `yt-dlp`. При скачивании выбирается лучшее доступное видео и аудио; они объединяются в MKV без перекодирования. Сам файл не улучшает исходное качество и не может скачать больше, чем предоставляет источник.

## Скачать

Собранный Windows x64 файл можно опубликовать во вкладке **Releases** GitHub. При первом запуске программа извлекает включённые компоненты в `%LOCALAPPDATA%\YouTubeDownloader` — установка прав администратора не нужна. Для скачивания требуется интернет.

## Возможности

- Простой интерфейс на русском языке.
- Ссылка на YouTube, выбор папки сохранения и журнал.
- Максимальное доступное качество без перекодирования.
- yt-dlp, FFmpeg/ffprobe и Deno включены в сборку.
- Обновление yt-dlp из интерфейса.

## Сборка из исходников

Требуется Windows x64, Windows PowerShell 5.1, Git, доступ в интернет, .NET Framework 4.x C# compiler и winget-пакеты `yt-dlp.yt-dlp`, `yt-dlp.FFmpeg` и `DenoLand.Deno`.

1. Установите компоненты, если их ещё нет:

   ```powershell
   winget install --id yt-dlp.yt-dlp --exact
   winget install --id yt-dlp.FFmpeg --exact
   winget install --id DenoLand.Deno --exact
   ```

2. Убедитесь, что файл `yt-dlp.exe` находится в `%LOCALAPPDATA%\YT-DLP-Downloader\yt-dlp.exe` (или поправьте путь в `Build.ps1`).
3. Запустите из этой папки:

   ```powershell
   .\Build.ps1
   ```

Сборка формирует `build\tools.zip` и `build\YouTubeDownloader.exe`. Встроенные бинарники копируются локально из установленных пакетов; их версии и лицензии нужно проверить перед публикацией нового релиза. В частности, standalone `yt-dlp.exe` содержит сторонние компоненты под GPLv3+; см. README и `THIRD-PARTY.txt` проекта yt-dlp. Для распространения сборки соблюдайте все применимые лицензии и включайте соответствующий исходный код и уведомления.
