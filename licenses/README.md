# Уведомления сторонних компонентов

При распространении собранного приложения включаются сторонние исполняемые файлы. Уведомления и применимые исходные материалы должны соответствовать конкретным версиям и сборкам бинарников, включённым в релиз. Смотрите [`../THIRD-PARTY.txt`](../THIRD-PARTY.txt), лицензионные файлы внутри `tools.zip` и первичные лицензии проектов. MIT для оболочки не заменяет их лицензии.

Windows-исполняемый файл yt-dlp может содержать код под GPLv3+. Для распространения такой сборки проверьте точный состав и обязательства по предоставлению Corresponding Source у yt-dlp и включённых компонентов. Одна лишь ссылка на репозиторий yt-dlp не всегда достаточна для соблюдения лицензии.
